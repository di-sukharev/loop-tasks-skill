# loop-tasks-skill

Оркестрация выбранной пачки задач с учётом зависимостей. Цель — абсолютно достаточно:
все требования выполнены, ничего лишнего, UX/UI прост. Минимум времени и токенов,
включая переделки.

Лид делегирует исследование и код, выдаёт небольшие подзадачи по одной с точным
definition of done и проверяет отчёты с доказательствами. Связанные подзадачи обычно
продолжает тот же исполнитель. Лид не читает историю саб-агентов; код смотрит,
когда так быстрее или надёжнее.

Каждая самостоятельная задача: [loop-code-review](https://github.com/di-sukharev/loop-code-review-skill)
→ проверки → коммит → push → следующая задача. Ревью учитывает взаимодействие задач;
точечные проверки допустимы раньше. Неотделимые изменения завершаются вместе.

Препятствия решаются как prerequisites текущей задачи и не увеличивают счётчик
пачки. Самостоятельные prerequisites проходят тот же цикл, затем продолжается
исходная задача. Остановка — когда нужно действие пользователя.

Коммиты и push включены по умолчанию; явные указания пользователя имеют приоритет.
Чужие изменения сохраняются. Полный протокол: [SKILL.md](loop-tasks/SKILL.md).

## Установка

Отправьте агенту:

```text
Install these skills globally:
https://github.com/di-sukharev/loop-code-review-skill
https://github.com/di-sukharev/loop-tasks-skill
```

Или скопируйте `loop-code-review` и `loop-tasks` в `~/.codex/skills/` либо
`~/.claude/skills/`. Нужна поддержка саб-агентов; `orchestration` не требуется.

## Использование

```text
$loop-tasks
Complete the next three open tasks in tasks/, one subtask at a time.
```

В Claude Code — `/loop-tasks`. Опционально задайте модели:

```text
$loop-tasks --sub gpt-5.6-luna --sub-sub gpt-6-astra
```

`--sub` — исполнитель, `--sub-sub` — каждый ревьюер; работают формы `=MODEL` и
обычный текст. По умолчанию — модель сессии; модель лида сохраняется.
Недоступная модель не подменяется молча.
