# loop-tasks-skill

`loop-tasks` — агентный скилл для последовательного выполнения пачки связанных задач. Оркестратор не трогает код: он выдаёт каждую задачу отдельному свежему рабочему агенту, обрабатывает внутренние зависимости и пропускает задачу дальше только после ревью, коммита, push и чистого рабочего дерева.

Рабочий агент сам вызывает [`loop-code-review`](https://github.com/di-sukharev/loop-code-review-skill) и исправляет только P0/P1: ошибки поведения, регрессии, уязвимости, потерю данных, нарушения контрактов и проверки, сломанные изменениями задачи. Стиль, нейминг и необязательные рефакторинги не задерживают цикл.

## Установка

Сначала установите `loop-code-review`, затем скопируйте папку `loop-tasks` из этого репозитория в каталог скиллов.

Codex:

```sh
mkdir -p ~/.codex/skills
cp -R loop-tasks ~/.codex/skills/
```

Claude Code:

```sh
mkdir -p ~/.claude/skills
cp -R loop-tasks ~/.claude/skills/
```

## Использование

- `$loop-tasks` в Codex;
- `/loop-tasks` в Claude Code;
- либо попросите агента последовательно выполнить весь переданный список задач через свежих саб-агентов.

Перед запуском нужен чистый Git worktree и настроенный push текущей ветки. В конце скилл перечисляет выполненные задачи, созданные коммиты и ветку назначения.
