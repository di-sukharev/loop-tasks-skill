# loop-tasks

Пачка задач: свежий саб-агент на каждую задачу → изучение кода и выбор режима →
реализация и проверки →
[loop-code-review](https://github.com/di-sukharev/loop-code-review-skill) всей задачи →
коммит и push → следующая задача.

Исполнитель выбирает режим после изучения кода:

- **Light:** локальное изменение, понятное поведение и способ проверки —
  реализация без промежуточных согласований.
- **Full:** связанные изменения, миграции или существенная неопределённость —
  лид одобряет план; контрольные точки нужны только для существенных решений.

Если в процессе понадобился Full, исполнитель сообщает до расширения работ.

Цель — все требования, продуманный простой UX и минималистичный UI без лишних
кликов, модалок и кнопок. Лид напрямую управляет саб-агентами, не читает проектные файлы и их истории;
задаёт открытые вопросы только при существенной неопределённости.
Лид отвечает за качество и срок: каждый шаг продвигает задачу или снимает неопределённость.
Свежий проверяющий саб-агент ищет доказуемые дефекты, исправляет принятые лидом
замечания; следующий независимо проверяет результат.

Prerequisite добавляется только если без него нельзя завершить текущую задачу.
Самостоятельный prerequisite проходит тот же цикл, затем работа возвращается
к исходной задаче; счётчик пачки не растёт. Неотделимые изменения идут вместе.
Остановка — только для действия человека. Все требования выполняются без лишних
улучшений. Посторонние изменения не трогаем и не включаем в работу, ревью и коммиты.
Работаем в текущей ветке, если не указано иное. Продакшен, новые ветки и worktree —
только с разрешения пользователя.
Перед ревью саб-агент завершает реализацию и запускает проверки, полезные для
изменений или обязательные в проекте; лишние и повторные пропускает.
Саб-агенты работают по коду; для визуальной проверки браузер не открывают и
приложение не прокликивают. Визуальная приёмка — пользователю.
[Полный протокол](loop-tasks/SKILL.md).

## Установка и запуск

Отправьте агенту:

```text
Install these skills globally:
https://github.com/di-sukharev/loop-tasks-skill
https://github.com/di-sukharev/loop-code-review-skill
```

Или скопируйте обе папки скиллов в `~/.codex/skills/` либо `~/.claude/skills/`.
Нужны саб-агенты; `orchestration` не требуется.

```text
$loop-tasks
Complete the next three open tasks in tasks/.
Use gpt-5.6-luna for all subagents.
```

Claude Code: `/loop-tasks`. Модель всех саб-агентов задаётся обычным текстом.
По умолчанию: Codex — `gpt-5.6-luna`,
Claude Code — `sonnet`. Недоступную модель не подменяем.
