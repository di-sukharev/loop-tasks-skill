# loop-tasks

Пачка задач: свежий саб-агент на каждую задачу → план с edge cases и проверками →
последовательная реализация подзадач без промежуточных согласований →
[loop-code-review](https://github.com/di-sukharev/loop-code-review-skill) всей задачи →
коммит и push → следующая задача.

Лид напрямую управляет саб-агентами, не читает проектные файлы и их истории;
задаёт открытые вопросы только при существенной неопределённости.
Свежий проверяющий саб-агент ищет доказуемые дефекты, исправляет принятые лидом
замечания; следующий независимо проверяет результат.

Самостоятельный prerequisite проходит тот же цикл, затем работа возвращается
к исходной задаче; счётчик пачки не растёт. Неотделимые изменения идут вместе.
Остановка — только для действия человека. Все требования выполняются без лишних
улучшений; чужие изменения сохраняются, указания пользователя имеют приоритет.
Быстрые проверки — до передачи результата, обязательные — до завершения;
визуальная проверка — пользователю. [Полный протокол](loop-tasks/SKILL.md).

## Установка и запуск

Отправьте агенту:

```text
Install these skills globally:
https://github.com/di-sukharev/loop-tasks-skill
https://github.com/di-sukharev/loop-code-review-skill
```

Или скопируйте обе папки скиллов в `~/.codex/skills/` либо `~/.claude/skills/`.
Нужны саб-агенты; `orchestration` не требуется.

```text
$loop-tasks --sub gpt-5.6-luna
Complete the next three open tasks in tasks/.
```

Claude Code: `/loop-tasks`. `--sub MODEL`, `--sub=MODEL` или обычный текст
задают модель всех саб-агентов. По умолчанию: Codex — `gpt-5.6-luna`,
Claude Code — `sonnet`. Модель лида сохраняется; недоступную не подменяем.
