# loop-tasks-skill

Лид ведёт выбранную пачку задач, сохраняя контекст требований и решений.
Проектные файлы и истории саб-агентов не читает; исследование, код и проверки
делегирует напрямую, без вложенных саб-агентов.

На каждую большую задачу — свежий реализующий саб-агент. Он предлагает план
на уровне идеи, edge cases и проверки. Лид задаёт открытые вопросы только при
существенной неопределённости. Затем тот же саб-агент выполняет все подзадачи
последовательно без промежуточных согласований и приносит доказательный отчёт.

После реализации всей задачи — [loop-code-review](https://github.com/di-sukharev/loop-code-review-skill).
Свежий проверяющий саб-агент получает исходные требования и проверяет все изменения
и затронутые зависимости. Лид принимает замечания, тот же саб-агент исправляет,
следующий проверяет обновлённый результат. Быстрые проверки — до передачи результата;
обязательные проверки должны пройти перед завершением. Визуальная проверка — пользователю.

Препятствия решаются как prerequisites текущей задачи и не увеличивают счётчик
пачки. Самостоятельный prerequisite проходит ревью, проверки, коммит и push,
затем продолжается исходная задача. Неотделимые изменения завершаются вместе.
Остановка — только когда нужно действие человека.

После завершения большой задачи — коммит и push, затем следующая задача.
Все требования выполняются без лишних улучшений. Чужие изменения сохраняются;
явные указания пользователя имеют приоритет.
Полный протокол: [SKILL.md](loop-tasks/SKILL.md).

## Установка

Отправьте агенту:

```text
Install these skills globally:
https://github.com/di-sukharev/loop-code-review-skill
https://github.com/di-sukharev/loop-tasks-skill
```

Или скопируйте `loop-code-review` и `loop-tasks` в `~/.codex/skills/` либо
`~/.claude/skills/`. Нужна поддержка саб-агентов; `orchestration` не требуется.

## Использование

```text
$loop-tasks --sub gpt-5.6-luna
Complete the next three open tasks in tasks/.
```

В Claude Code — `/loop-tasks`. `--sub MODEL`, `--sub=MODEL` или обычный текст
задают единую модель всех реализующих и проверяющих саб-агентов.
По умолчанию — `gpt-5.6-luna` в Codex, `sonnet` в Claude Code.
Модель лида сохраняется; недоступная модель не подменяется молча.
