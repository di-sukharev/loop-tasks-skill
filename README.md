# loop-tasks-skill

`loop-tasks` ведёт очередь готовых задач: учитывает зависимости, выбирает
исполнителей и принимает результат. Цель — абсолютно достаточный результат
за минимум времени и токенов. Решения — минимально достаточные.

Минимально достаточно — самая простая и элегантная реализация, которая полностью
закрывает acceptance criteria. UX/UI остаётся простым, без лишних продуктовых
решений. Необязательные улучшения пользователь запросит отдельно; требования
задачи должны быть выполнены сразу.

Задачи разбиваются на небольшие подзадачи и выполняются по одной: следующая —
после проверки предыдущей. Связанные подзадачи обычно делает один исполнитель.
Оркестратор получает короткие отчёты, не читает историю саб-агентов и при
необходимости смотрит код сам.
Ревью выполняется через `loop-code-review`; границы проверок выбираются по задаче.
Коммиты и push — согласно запросу пользователя.

## Установка

Отправьте агенту:

```text
Install these skills globally:
https://github.com/di-sukharev/loop-code-review-skill
https://github.com/di-sukharev/loop-tasks-skill
```

При ручной установке скопируйте папки `loop-code-review` и `loop-tasks` из
соответствующих репозиториев в `~/.codex/skills/` или `~/.claude/skills/`.
Нужна среда с поддержкой саб-агентов. `orchestration` не обязателен.

## Использование

```text
$loop-tasks
Complete the next three open tasks in tasks/, one subtask at a time.
```

В Claude Code используйте `/loop-tasks`. При желании укажите модели:

```text
$loop-tasks --sub gpt-5.6-luna --sub-sub gpt-6-astra
Complete the next three open tasks in tasks/, one subtask at a time.
```

`--sub` — исполнитель, `--sub-sub` — каждый ревьюер. Поддерживаются `--sub=MODEL`,
`--sub-sub=MODEL` и выбор обычным текстом. Без параметров действуют настройки
и наследование модели приложения. Недоступная модель не подменяется молча.
