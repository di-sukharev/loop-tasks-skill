# loop-tasks-skill

`loop-tasks` — оркестрация пачки задач. Один лид отвечает за результат, учитывает
зависимости и границы пачки. Цель — абсолютно достаточный результат: все требования
выполнены, ничего лишнего. Минимум времени и токенов, включая переделки.

Решения — минимально достаточные: самая простая и элегантная реализация, которая
закрывает acceptance criteria. UX/UI без лишней сложности; необязательные улучшения
пользователь запросит отдельно. Требуемое поведение нельзя отложить как полировку.

Лид делегирует исследование и код, получает короткие отчёты с доказательствами.
Историю саб-агентов не читает; код смотрит сам, когда так быстрее или надёжнее.
Задачи разбивает на небольшие подзадачи с точным definition of done и выдаёт
по одной, принимая результат предыдущей. Связанные подзадачи и задачи обычно
продолжает тот же исполнитель.

Каждая самостоятельная задача проходит [loop-code-review](https://github.com/di-sukharev/loop-code-review-skill),
проверки и коммит до начала следующей. Связанные изменения можно объединять
в один законченный результат. Основные проверки — после ревью; точечные можно
раньше. Лид учитывает взаимодействие задач и сообщает, что реализовано, проверено,
закоммичено и ещё не завершено.

Коммиты — часть стандартного процесса; отдельно просить их не нужно. Явные указания
пользователя имеют приоритет. Push — по запросу. Чужие изменения сохраняются.

## Установка

Отправьте агенту:

```text
Install these skills globally:
https://github.com/di-sukharev/loop-code-review-skill
https://github.com/di-sukharev/loop-tasks-skill
```

При ручной установке скопируйте папки `loop-code-review` и `loop-tasks` из
соответствующих репозиториев в `~/.codex/skills/` или `~/.claude/skills/`.
Нужна среда с поддержкой саб-агентов. `orchestration` не обязателен.

## Использование

```text
$loop-tasks
Complete the next three open tasks in tasks/, one subtask at a time.
```

В Claude Code используйте `/loop-tasks`. При желании укажите модели:

```text
$loop-tasks --sub gpt-5.6-luna --sub-sub gpt-6-astra
Complete the next three open tasks in tasks/, one subtask at a time.
```

`--sub` — исполнитель, `--sub-sub` — каждый ревьюер. Поддерживаются `--sub=MODEL`,
`--sub-sub=MODEL` и выбор обычным текстом. Для неуказанных ролей используется модель
текущей сессии; модель лида сохраняется. Недоступная модель не подменяется молча.
